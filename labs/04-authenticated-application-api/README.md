# Lab 04 — Authenticated application API

**Status:** Prepared — gated; not the active lab

**Current exercise when activated:** Level 1 — Guided implementation

**Region:** `ap-southeast-1` (Singapore), unless a required feature is unavailable

Build and validate a small API Gateway REST API backed by Lambda and authenticated with an Amazon Cognito user pool. The lab distinguishes authentication (proving who the caller is) from authorization (deciding what that caller may do), and includes request validation, runtime evidence, cost controls, and cleanup.

See [`LAB.md`](LAB.md) for the assignment, [`HINTS.md`](HINTS.md) for progressive Level 1 guidance, [`TESTS.md`](TESTS.md) for evidence requirements, and [`CLEANUP.md`](CLEANUP.md) for teardown. No AWS resources are created by preparing these files. Begin only when the curriculum progression gate reaches Lab 04 and provisioning has been explicitly approved.
