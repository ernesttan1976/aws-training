# Lab 02 — Data access patterns and lifecycle management

**Status:** Planned — authored; not active until Lab 01 is assessed
**Current exercise when activated:** Level 1 — Guided implementation
**Region:** `ap-southeast-1` (Singapore), unless a required feature is unavailable
**DVA-C03 mapping:** Domain 1, Task 1.3 — use data stores during application development.

Build a small field-report application using DynamoDB for queryable metadata and Amazon S3 for attachments. The lab exercises access-pattern design, a secondary index, logical expiry with DynamoDB TTL, and an S3 lifecycle rule. Runtime evidence and the learner's explanation are required before any competency is marked demonstrated.
