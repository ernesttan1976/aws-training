# Lab 09 — Optimize a working AWS application

**Status:** Prepared — gated; Lab 01 remains active pending learner evidence and assessment

**DVA-C03 mapping:** Domain 4, Task 4.3 — optimize applications using AWS services and features

**First exercise when activated:** Level 1 — Guided optimization

This lab measures and tunes a small read-heavy serverless lookup API. The learner establishes a repeatable baseline, compares Lambda memory configurations and a bounded in-process cache, then justifies the resulting latency, cost, concurrency, and freshness trade-offs. It uses no paid cache service or sustained load test.
